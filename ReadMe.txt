Getting Started
1. Go to https://letos.org/ and download the installer
2. Run the installer and open it
Now you have a graphical interface version of SQLite

Importing
1. Pull the .db file from GitHub
2. Open Letos (4.0.4)
3. Click Database > Add a database 
4. Find the .db file in your file explorer and open it

Exporting
1. Save .db file
2. Push it to the GitHub

Creating a table
1. Right click on Tables > Create a table
2. Enter the table name
3. Double click the empty space under Name | Data type | etc...
4. Add the appropriate key type
   > If you need to alter this later, just double click the row
5. Enter the appropriate info
6. Apply the appropriate constraints
7. Press Okay
8. When done with all rows, press the green check mark to save
9. Press OK
10. Push to GitHub
